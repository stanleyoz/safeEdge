SafeEdge ◆ Map Calibrator

Pairs landmarks between the camera frame and a scaled site map to fit the image → ground homography. 1. Load both images. 2. Set scale: click two map points a known distance apart and type it. 3. Add points: click a ground-level landmark in the frame, then the same spot on the map (post bases, kerb noses, bay-line ends; never car bodies or tops of objects). 4. Optional lines: click two map points along a straight edge (kerb, path edge), then two or more frame points anywhere on that edge. At least 4 points, spread near and far, left and right; 8 or more is better. Export the JSON and run tools/check_homography.py on it. Nothing leaves this page.
